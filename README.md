# Tawny

**Your voice, exactly where you type.**

Tawny is a keyboard-first voice layer for your desktop. One shortcut -- dictate text, rewrite selections, generate images, or ask questions -- in any app, without switching windows.

[Download Early Preview](https://github.com/Priyank911/Tawny/releases) &nbsp;|&nbsp; [Live Site](https://priyank911.github.io/Tawny-web/)

---

## Features

| | |
|---|---|
| Dictate | Press the shortcut, speak, release. Text lands at your cursor in any app. |
| Rewrite | Select text, speak an instruction. Tawny replaces the selection with the result. |
| Generate images | Describe an image. It copies to clipboard and pastes into the active window. |
| Ask | Speak a question with text selected. The answer pastes at the cursor. |

## Platforms
